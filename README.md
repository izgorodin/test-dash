# Asset Dashboard (Vite + React)

Мини-приложение с тёмной темой и графиком стоимости активов по датам (Recharts).

## Локальный запуск

1. Установите зависимости: `npm i`
2. Запустите dev-сервер: `npm run dev`

## Сценарии npm

- npm run dev — локальный сервер
- npm run build — сборка
- npm run preview — просмотр сборки
